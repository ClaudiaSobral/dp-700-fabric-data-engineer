# Ingest Data with Dataflows Gen2 in Microsoft Fabric

## Dataflows Gen 2

- Dataflows é um processo de ETL dentro da plataforma Fabric, que pode absorver várias fontes de dados.
- Cria estruturas reutilizáveis de ETL
- É possível agendar refreshes (atualizações que pegam o dado da fonte)
- É uma solução low-code
- Não suporta RLS
- Precisa de capacidade Fabric
